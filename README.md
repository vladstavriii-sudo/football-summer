# Football Summer — CreativeByte

Адаптивный лендинг на HTML, CSS и JavaScript. Это актуальная основная версия проекта.

## Запуск

Откройте `index.html` в браузере либо запустите локальный сервер из этой папки:

```sh
python3 -m http.server 8080
```

Затем откройте http://localhost:8080.

## Состав

- `index.html` — разметка страницы.
- `styles.css` — оформление, мобильная версия и анимации.
- `app.js` — меню, переходы между блоками, карточки и калькулятор.
- `banner.js` — анимированный баннер для компьютера и статичный баннер для телефона.
- `assets/` — изображения, Jura Light/SemiBold и локальная библиотека Lenis.

Сборка и установка зависимостей не требуются. Все используемые ресурсы находятся в папке проекта.

## Калькулятор

Фрибет — 12,5% от суммы ставок, максимум 200 EUR.

## Перед публикацией

Кнопки участия, внешние разделы, приложения и соцсети пока показывают информационные окна: реальные ссылки нужно подключить. Финальные тексты политик и условий также нужно добавить. GitHub Pages может публиковать содержимое корня этого проекта без сборки.
