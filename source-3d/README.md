# Football Summer — 3D concept

Десктопная версия 1440 px на React + TypeScript + Vite, Three.js и Lenis. Мобильная версия не разработана.

## Локальная работа

```sh
npm ci
npm run dev
```

## Публикация в GitHub Pages

```sh
npm run export:pages
```

Команда собирает проект и обновляет отдельную папку `../3d/`. Основной вариант в корне репозитория сохраняется.

В приложении используются относительные пути: модели GLB, JSON-настройки, шрифты и логотип загружаются из подпапки сайта. Сцены Hero и участия интерактивны. Кнопки участия — демонстрационные, реальные ссылки и официальные условия не подключены. Калькулятор использует предварительные 25%.
