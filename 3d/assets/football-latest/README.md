# Latest approved football models

Eight self-contained GLB 2.0 files, with embedded textures, copied from the approved local viewer. Existing assets and app code were left in place.

Load URLs: /assets/football-latest/<id>.glb

IDs: teamgeist, ucl, trionda, nike-hivis, puma, nike-third, brazuca, nike-t90.

See manifest.json for exact face quaternions, centering/scaling and the shared lime rim lighting. Centre each imported model and normalize its diameter to 1.88 before applying the holder orientation. Keep the chosen face directed at the camera, with small tilts only. Puma has the repaired clean cat logo; its preferred quaternion is required to show this side. Trionda keeps the existing inner-wrap rotation of PI around Z.

The reverse of photographic reconstructions is inferred; these files are intended for the approved front-facing presentation.
