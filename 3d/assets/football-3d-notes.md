# Последние 3D-ассеты Football Summer

- `/assets/trionda.glb` — скачанный ранее мяч Trionda, использованный в последнем просмотре.
- `/assets/suitcase.glb` — кейс с отдельными крышкой и замками.
- `/assets/freebet-creativebyte.glb` — последняя форма билета, сквозная перфорация, отдельный корешок, логотип CREATIVE / BYTE.

Все текстуры встроены в GLB; внешние картинки для загрузки моделей не нужны. Файлы проверены по SHA-256 и структуре GLB.

## Чтобы получить последний вид

Настройки находятся в `football-3d-settings.json`: свет отдельно для каждого объекта, почти чёрный фон с минимальным зелёным ореолом, камеры, материалы, мягкая тень и салатовый отсвет плоскости, положения объектов, веер из трёх копий и параметры взаимодействий.

**Эти настройки не встроены в GLB.** Последние изменения света и hover сделаны в Three.js. Простая замена GLB сама по себе не меняет освещение сайта.


Сначала применить материалы, затем копировать билет в веер. Не запускать сохранённые GLB-клипы одновременно с ручным управлением теми же узлами. Повороты в JSON указаны в радианах, кроме явно названных полей Degrees.

Для кейса важно отключить normalMap у leather/foam и использовать FrontSide — так не возникают яркие зелёные артефакты. Копировать influence массивы morph targets для каждого билета отдельно. Веер и реакция на курсор создаются кодом; в файле билета находится одна модель.

Код сайта в этой операции не изменялся.
